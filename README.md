# Terwilliger algebras in Lean 4

A formalization of P. Terwilliger's *Lecture Note on Terwilliger Algebra*
(edited by H. Suzuki), <https://icu-hsuzuki.github.io/t-algebra/>, carried out
modulo Mathlib.

The library builds against Lean `v4.33.1` and the Mathlib snapshot installed at
`/opt/mathlib`.  It is ~24000 lines.  **All forty chapters are represented**:
every labelled definition of the notes is formalized, and every labelled result
has a Lean statement.  **7 statements are still `sorry`** (all in Chapters 33–40,
each with a refutation-checked restatement and a precise gap docstring); everything
else is
checked.  [COVERAGE.md](COVERAGE.md) records the status of each of the 133
labelled environments of the book; [ROADMAP.md](ROADMAP.md) says what is missing
where and in what order it should be filled in.

```
./build.sh          # elaborates every module, then the root file
```

In this VM `/opt/mathlib` is read-only and already carries built oleans, so the
build goes through `build.sh` (which puts the repository on `LEAN_PATH`) rather
than through `lake build`, and `lakefile.toml` pins Mathlib by path
(`/opt/mathlib`).  In a standalone checkout replace that `[[require]]` block by
the usual Mathlib dependency (`scope = "leanprover-community"`, a `rev` matching
`lean-toolchain`) and build with `lake build`.

```lean
import Terwilliger
open Terwilliger
```

## The design

* **Vertices are a `Fintype`.**  A graph is a `SimpleGraph X`; `Mat_X(K)` becomes
  `Matrix X X 𝕜` and the standard module `V = K^X` becomes `X → 𝕜`, so that
  `A *ᵥ v` is `Matrix.mulVec`.
* **The field is `RCLike 𝕜`**, i.e. `ℝ` or `ℂ` — exactly the two fields the notes
  allow.  The Hermitian form is written directly as `w̄ ᵀ v`.
* **`T(x)` is a `StarSubalgebra`,** generated by the self-adjoint matrices `A` and
  `Eᵢ*(x)`.  This makes Lemma 1.8 (i) (`a ∈ T ⇒ a* ∈ T`) true by construction and
  lets Lemma 1.8 (ii) be proved from `StarMemClass.star_mem`.
* **The spectral decomposition is a hypothesis record.**  The notes begin by
  invoking the spectral theorem for real symmetric matrices.  (This Mathlib
  snapshot does have `Matrix.IsHermitian.spectral_theorem` in
  `Mathlib/Analysis/Matrix/Spectrum.lean` — an earlier note in this file said
  otherwise — but the chapters 20–27 and 28–40 statements were already framed
  relative to explicit data, so they stay that way.)  The primitive
  idempotents, the eigenvalues `θᵢ`, the dual eigenvalues `θ*ᵢ` and the Krein
  parameters are bundled into `SchemeData` (Chapters 20–27) and `DRGData`
  (Chapters 28–40).  Every theorem of those chapters is stated relative to that
  bundle, which is the running assumption of the notes.

## What is proved, precisely

* `adj_transpose`, `star_adj`: `A` is symmetric and self-adjoint.
* `adj_mulVec_single`: `A x̂ = ∑_{y ∼ x} ŷ`.
* `subconst_mul_subconst`: `Eᵢ* Eⱼ* = δᵢⱼ Eᵢ*`; `sum_subconst_eq_one`: `∑ᵢ Eᵢ* = 1`.
* `isStable_orthCompl`, `isStable_orthCompl_subconstituent`: **Lemma 1.8 (ii)**.
* `subconst_mul_adj_mul_subconst_eq_zero`: **Lemma 4.3 (i)**.
* `commute_of_mem_dualBoseMesner`: `M*(x)` is commutative.
* `isReducibleMatrix_sq_of_isBipartiteMatrix`: Chapter 2, note 2.
* `cayley_adj`, `cayley_left_mul_adj`, `cayley_vertexTransitive`,
  `cayley_stabilizer_trivial`, `cayley_leftRegular_injective`: **Theorem 3.5 (i)**.
* `adj_mulVec_sphereSum`: **Lemma 12.1**,
  `A Sᵢ = b_{i-1}S_{i-1} + aᵢSᵢ + c_{i+1}S_{i+1}`.
* `symmetric_implies_commutative`: the implication `(S) ⇒ (C)` of **Theorem 7.4**.
* `distMatrix_zero`, `distMatrix_one`, `sum_distMatrix`, `distMatrix_transpose`.
* `assocMatrix_mul`: **Definition 17.2 (iv')**, `AᵢAⱼ = ∑ₕ p^h_{ij}Aₕ`.
* `perron_frobenius`: **the Perron–Frobenius theorem** (Theorem 2.4 (i), (ii)),
  proved by Collatz–Wielandt — `quad C v = v ⬝ᵥ (C *ᵥ v)` is maximised over the
  nonnegative unit sphere (`isCompact_K`, `exists_maximizer`), the first-order
  condition (`first_order_general`) forces a maximiser to be strictly positive
  (`maximizer_pos`), to solve the eigenvector equation (`maximizer_eigen`), to have
  a positive eigenvalue (`quad_pos_of_ne_zero`), to dominate every eigenvalue
  (`eigenvalue_le_quad`), and to be unique up to scale (`eigenvector_unique`).
* `isIrreducible_adj`, `largest_eigenvalue_le_max_valency`: **Lemma 1.2 (i)**, via
  Perron–Frobenius applied to the adjacency matrix of a connected graph (whose
  irreducibility is the `mem_of_reachable` closure argument).
* `largest_eigenvalue_eq_valency`: **Lemma 1.2 (ii)** — for a connected regular
  graph the spectral radius is exactly the valency.
* `sphereSpan_isStable`, `trivialModule_le_sphereSpan`, `trivialModule_thin`,
  `trivialModule_thin_of_distanceRegular`, `linearIndependent_sphereSum`:
  **Lemma 12.1, (iii) ⇒ (i) and (ii)** — for a graph distance-regular at `x`,
  the sphere sums span the trivial `T(x)`-module, are linearly independent on
  nonempty spheres, and the trivial module is thin.
* `exists_perron_data`, `krylov`, `exists_eigenvector_mem_krylov`,
  `perron_mem_trivialModule`: the Perron vector of a connected graph with at
  least two vertices lies in the trivial `T(x)`-module for every `x` (a
  Krylov-space argument: otherwise `v ↦ Av - θ₀v` is injective, hence
  surjective, and pairing `x̂ = Av - θ₀v` with `δ` contradicts `δ > 0`).
* `exists_smul_of_finrank_le_one`, `subconst_mulVec_apply`, `exists_adj`,
  `perron_const_on_neighbors`, `perron_const_of_even_walk`,
  `perron_const_on_sphere`, `subconst_mulVec_perron`: **Lemma 12.1,
  (i) ⇒ (ii), first half** — thinness at every vertex makes `E₁*(w)δ` a
  multiple of `Aŵ`, so the Perron vector is constant on neighbourhoods, hence
  along even walks, hence on spheres, and `Eᵢ*(x)δ = cᵢ Sᵢ(x)`.
* `sphereSum_mem_trivialModule_perron`, `sphereSpan_le_trivialModule_perron`,
  `mulVec_sum_subconst`, `trivialModule_le_sphereSpan_perron`:
  **Lemma 12.1, (i) ⇒ (ii), second half** — the sphere sums lie in the trivial
  module, and conversely the subconstituent projections decompose every
  element of the trivial module into pieces of the thin lines through
  `Eᵢ*(x)δ ≠ 0`, which are multiples of the sphere sums.
* `ConstantOnSpheres`, `isDistanceRegularAt_of_adj_mem_sphereSpan`,
  `isDistanceRegular_of_sphereSpan_eq`: **Lemma 12.1, (ii) ⇒ (iii)** — if
  `A` maps every sphere sum into the sphere span, its value at `z` counts the
  neighbours of `z` in each sphere, so the intersection numbers depend only on
  the sphere: distance-regularity.
* `sphereSpan_eq_trivialModule_of_thin`, `lemma12_1_i_iff_ii`, `lemma12_1_iff`:
  **Lemma 12.1 in full** — for a connected graph with at least two vertices,
  thinness of the trivial module at every vertex, the sphere sums spanning the
  trivial module at every vertex, and distance-regularity are equivalent.
* `isStable_trivialModule`, `sphereSum_eq_sum_single`.
* `Hermitian.lean`: the Hermitian pairing layer — `star_mulVec_dotProduct`,
  `selfAdj_star_dotProduct`, `vnorm` with Cauchy–Schwarz
  (`abs_star_dotProduct_le_vnorm`, transported from `EuclideanSpace` without
  creating an instance on `X → ℂ`), disjoint-support orthogonality, the band
  lemma `Eᵢ* Aᵐ Eⱼ* = 0` for `|i-j| > m`, and the hand-rolled orthogonal
  decomposition `exists_orthogonal_decomp`.
* `Spectral.lean`: the spectral projections of a self-adjoint matrix —
  `IsEigenvalue`, `eigFinset` (eigenvalues real), the squarefree annihilator,
  `spectralProj` (the Lagrange projection, a polynomial in `A`) with its full
  package, `star_aeval`, and the named spectral theorem forms:
  `spectral_theorem` (`A = ∑θ θ • E_θ`), `exists_orthonormal_eigenbasis`,
  `eigFinset_sq`.
* **Lemma 9.2** (`Thin.lean`): `thin_parameters_real` (`aᵢ ∈ ℝ`, `xᵢ > 0`),
  `thin_module_structure` (the `wᵢ = E*_{r+i}Aⁱw₀` basis with the tridiagonal
  action `A wᵢ = w_{i+1} + aᵢ wᵢ + xᵢ w_{i-1}`), `thinPoly_aeval`,
  `thinPoly_monic_degree`.
* **Lemma 12.2** (`TwoThin.lean`): `lemma12_2_i` (the two projection formulas
  with the sharp degree bounds), `lemma12_2_ii` (the eigenvalue identities with
  the spectral measures, in the corrected normalization and conjugate placement
  — the notes' form is false as printed), `lemma12_2_iii` (`p(θ)p'(θ) ∈ [0,1]`
  at eigenvalues where both measures are nonzero — the notes' argument divides
  by `m(θ)m'(θ)` there).
